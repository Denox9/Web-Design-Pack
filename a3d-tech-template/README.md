# A3-D Technical Editorial Website Template

A self-contained HTML/CSS/JavaScript package inspired by the supplied monochrome technical idea board with a lime signal accent. The RX09 TechFlux files were used only as a structural reference for package organization and page coverage.

## Included
- `index.html` responsive landing page
- `components.html` reusable UI inventory
- `404.html` error page
- `assets/css/a3d.css` tokens, layout, components and responsive rules
- `assets/js/a3d.js` menu, theme, counters and demo form behavior
- `assets/svg/icons.svg` SVG symbol sprite
- `assets/svg/mark.svg` standalone project mark/favicon

## Start
Open `index.html` directly, or serve the folder with any static web server.

## Customize
1. Edit the color tokens at the top of `assets/css/a3d.css`.
2. Replace sample copy in `index.html`.
3. Edit SVG symbols in `assets/svg/icons.svg`.
4. Connect the contact form to your preferred backend. The included form is demo-only.

## Design direction
- Black/white technical editorial system
- Lime `#C7FF3B` as the single signal accent
- Oversized typography, modular grids, strict borders
- Inline and sprite-based SVG only
- Light/dark themes and reduced-motion support
- No frameworks, external fonts, images or network dependencies
