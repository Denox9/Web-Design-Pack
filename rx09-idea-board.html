Vertical Poster

1 SPECIMENUSE: LANDING HERO / 404 / LAUNCH
N-01

Rotated Identifier

One giant code set in writing-mode:vertical-rl. Becomes the landing hero spine; content runs beside it.

N-02

Dot Field

SVG pattern behind the type. Theme-aware fill, no images, scales with the container.

N-03

Pixel Checker

8-bit squares used as a transition between headline and data. Pair with one orange cell.

N-04

Rail Labels

A0/5, A1/B, B0/7: bracket rail with filled / outline bars. Works as a stepper or a status legend.

N-05

Spec Footer

Font name, weight and size printed as content. Use on about / colophon pages.
